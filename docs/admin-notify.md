# 報名後台：入帳通知與行前通知

程式：`apps-script/admin/notify.gs`，跟後台主程式放在同一個 Apps Script 專案（綁在「報名後台」試算表）。
信件一律由部署 Apps Script 的協會 Workspace 帳號寄出（GmailApp，每日約 1,500 位收件人）。

## 會用到的工作表

| 工作表 | 寄信需要的欄位 |
| --- | --- |
| 活動設定 | 活動ID、活動名稱、活動日期、費用、行前通知主旨、行前通知內文、行前通知寄出時間 |
| 繳費狀態 | 活動ID、報名鍵、姓名、Email、應繳金額、已入帳、入帳金額、入帳日期、帳號後五碼、入帳通知寄出時間、行前通知寄出時間 |
| 寄信紀錄 | 時間、活動ID、報名鍵、收件人、類型、結果、操作者（沒有的話第一次寄信時會自動建立） |

「繳費狀態」若有「報名狀態」欄（正常／備取／取消，空白視為正常）：「取消」的人兩種通知都不寄，「備取」的人不寄行前通知。

只有管理員（「報名後台」試算表「管理員」工作表 A 欄列出的信箱，以及部署帳號本人）可以預覽或寄信。

程式依「標題名稱」找欄位，欄位順序可以調整、也可以多加其他欄；但上面列的欄位少了任何一個就不會寄信，並告訴你缺哪一欄。

## 入帳通知

1. 「帳號後五碼」由學員在報名表填寫、同步進「繳費狀態」。對帳的管理員拿它和銀行入帳紀錄比對，填入「入帳金額」「入帳日期」，確認無誤後勾選「已入帳」。
2. 選單「協會後台 → 寄出入帳通知…」，輸入活動ID。
3. 確認視窗會顯示：要寄幾封、哪些人被略過（沒勾已入帳、金額／日期／帳號後五碼沒填、Email 有誤）、入帳金額和應繳金額不同的人，以及一封範例信。按「是」才會寄。
4. 寄出後「入帳通知寄出時間」會填上時間，「寄信紀錄」多一列。

勾錯了只要還沒按寄出，取消勾選就好，不會寄任何信。

## 行前通知

1. 在「活動設定」該梯次那一列填「行前通知內文」（主旨可留空，會用預設主旨）。
2. 選單「協會後台 → 寄出行前通知…」，輸入活動ID。
3. 只會寄給**已勾選「已入帳」**的人；之後才入帳的人，再按一次就只會寄給還沒收過的人。

行前通知內文範例（可直接複製進儲存格；在儲存格內換行用 Ctrl/⌘ + Enter）：

```
{姓名} 您好：

「{活動名稱}」即將在 {活動日期} 出發，以下是行前通知：

【集合】
時間：07:00
地點：台北車站東三門

【裝備】
・登山背包、頭燈（含備用電池）
・保暖衣物、雨衣褲
・個人藥品、行動糧與 1.5L 飲水

【領隊聯絡】
○○○　09xx-xxx-xxx

有任何問題直接回覆這封信即可，期待山上見！
台灣自主登山能力推廣協會
```

## 信件範本可用的欄位

`{姓名}` `{Email}` `{活動名稱}` `{活動日期}` `{費用}` `{應繳金額}` `{入帳金額}` `{入帳日期}` `{帳號後五碼}`

入帳通知的主旨與內文寫在 `notify.gs` 最上方的設定區（`PAYMENT_SUBJECT`、`PAYMENT_BODY`），寄件人名稱與回覆信箱也在那裡改。

## 先寄一封給自己看

選單「協會後台 → 寄一封範例信給自己…」：選 1（入帳）或 2（行前）、輸入活動ID，會用第一位收件人的資料寄到你自己的信箱，主旨前面加「［範例］」，不會寫入任何寄出時間。選 3 會用假資料寄一封「新報名通知（給教練）」範例，並提醒該活動有沒有填負責教練Email。

## 防重複寄送

- 「入帳通知寄出時間」「行前通知寄出時間」只要有值就不會再寄。真的需要補寄給某人時，清空那一格再按寄出即可。
- 每寄成功一封就立刻寫入時間，所以中途失敗、逾時或額度用完，再按一次只會寄剩下的人。
- 寄送時鎖住整份文件，兩位幹部同時按也只會寄一次。
- 單次最多寄 150 封、約 4.5 分鐘就先停，畫面會告訴你還剩幾封。

## 給主程式的接口

- `notify.gs` 不定義 `onOpen`，主程式的 `onOpen` 請呼叫 `addNotifyMenuItems_(menu)`：

  ```js
  function onOpen() {
    var menu = SpreadsheetApp.getUi().createMenu('協會後台');
    // …主程式自己的項目…
    addNotifyMenuItems_(menu.addSeparator());
    menu.addToUi();
  }
  ```

- 後台網頁可用 `google.script.run` 呼叫（`type` 為 `'payment'` 或 `'pretrip'`）：
  - `previewNotices({type, activityId, keys?})`：只預覽，回傳 `recipients`、`skipped`、`warnings`、`sample`、`quota`
  - `sendNotices({type, activityId, keys?})`：寄出，`keys` 可指定只寄給哪些報名鍵；回傳 `sent`、`failed`、`remaining`、`stopReason`
  - `sendTestNotice({type, activityId})`：寄範例給自己
  - 失敗時一律回傳 `{ ok:false, error:'中文說明' }`
- 內部函式都以 `notify` 開頭，避免和同專案其他檔案撞名。
